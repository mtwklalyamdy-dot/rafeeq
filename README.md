# رفيقي — رفيقك في طريقك الأكاديمي

منصة أكاديمية عربية PWA لطلاب الجامعات في اليمن. صاحب المشروع: **فاروق مقبول الوصابي**.

© 2026 فاروق مقبول الوصابي — جميع الحقوق محفوظة

## الاختيار التقني

- Next.js 16 App Router وReact 19 لواجهة وخادم في مشروع واحد خفيف.
- PostgreSQL دائم مع Drizzle ORM ومخطط ذي 51 جدولًا.
- PWA وCache Storage لتثبيت التطبيق وحفظ الملفات المختارة دون اتصال.
- جلسات opaque عشوائية؛ لا تُخزن التوكنات نفسها بل SHA-256، وكلمات المرور bcrypt بكلفة 12.
- SMTP فعلي لـOTP وGoogle Gemini REST من الخادم فقط عند إعداد الأسرار.
- تخزين ملفات خاص خارج `public` مع فحص MIME والتوقيع والحجم وصلاحية التنزيل.

اختيرت PWA لأنها أقل كلفة بيانات وتعمل على هواتف متوسطة دون البدء مبكرًا في APK. وظائف الخادم وAI والإرسال لا تعمل دون اتصال.

## التشغيل

1. ثبّت Node.js 22 وPostgreSQL 15 أو أحدث.
2. انسخ `.env.example` إلى `.env` واضبط `DATABASE_URL` كسر بيئي.
3. ثبّت الاعتماديات: `npm install`.
4. طبّق المخطط: `npx drizzle-kit migrate` لقاعدة جديدة، أو `npx drizzle-kit push --config drizzle.config.json` في التطوير.
5. أضف إعدادات المشروع: `psql "$DATABASE_URL" -f scripts/seed.sql`.
6. أنشئ أول مدير بعد وضع متغيرات `ADMIN_*`: `node scripts/create-admin.mjs`، ثم احذف تلك المتغيرات.
7. تطوير: `npm run dev`. إنتاج: `npm run build` ثم استخدم مشرف عمليات مناسب لتشغيل `npm run start`.

لا يحتوي المشروع على بيانات دخول ثابتة، ولا يُرقّي أول مستخدم تلقائيًا إلى مدير.

## الأسرار والتكاملات

| المتغير | الغرض | الحالة عند التسليم |
|---|---|---|
| `DATABASE_URL` | PostgreSQL | مهيأ محليًا ومختبر |
| `RAFEEQ_ADMIN_EMAILS` | قائمة بريدية لصلاحيات الإدارة الفعّالة دون تعديل سجلات المستخدمين | مضبوطة في `.env.local` للحسابين المطلوبين؛ أعد تشغيل الخادم بعد تغييرها |
| `GEMINI_API_KEY` | المساعد والتلخيص والصوت | موجود ومختبر برد نصي فعلي من المزود |
| `GEMINI_MODEL` | اسم نموذج Gemini | اختياري، الافتراضي العامل `gemini-3.1-flash-lite` |
| `SMTP_*` و`MAIL_FROM` | OTP والاستعادة | مهيأة؛ نجح اتصال ومصادقة SMTP وقبول طلب إرسال تشخيصي، ولم يُتحقق من وصوله إلى صندوق حقيقي |
| Push | إشعارات نظام التشغيل | غير منفذ/غير مهيأ؛ الإشعارات داخل التطبيق فقط |
| تخزين كائنات | ملفات إنتاج موزعة | غير مهيأ؛ التخزين المحلي مناسب لمثيل واحد فقط |

## العمل دون إنترنت والمزامنة

- لا يُحفظ ملف إلا بعد ضغط الطالب «حفظ Offline».
- يجري التنزيل إلى Cache Storage ثم تُحدث البيانات الوصفية؛ إذا فشل التحديث تبقى النسخة القديمة.
- الملاحظات تُكتب محليًا فورًا وتدخل طابورًا بمعرف عملية UUID ثابت.
- يعيد `/api/sync` نفس نتيجة العملية المكررة بدل تنفيذها مرتين.
- سياسة التعارض: يقارن `clientUpdatedAt`؛ إذا كانت نسخة الخادم أحدث يعيد `409/conflict` ونسخة الخادم ولا يحذف التعديل المحلي. واجهة دمج تفصيلية يدوية ما زالت مطلوبة.
- تعرض لوحة الطالب تاريخ لقطة Offline وتحذيرًا بأنها قديمة.

## الأمان

- ملكية الموارد مفحوصة في مسارات الملاحظات والتسليمات والمجتمع والدعم والملفات.
- المندوب يحتاج توثيق البريد واعتماد الإدارة؛ يستطيع إنشاء مادة مرتبطة ببياناته أو العمل على مادة مسندة، ونشر وتعديل المحتوى والكتب والواجبات والاختبارات والإعلانات والتنبيهات. لا يستطيع الدرجات أو حسابات الطلاب.
- OTP عشوائي من `crypto.randomInt`، يُخزن كتجزئة bcrypt مملحة ومرتبطة بالمستخدم والغرض، 10 دقائق، مرة واحدة، 5 محاولات، وإعادة إرسال محدودة.
- Rate limit داخل العملية مطبق للمصادقة وAI والمجتمع. للإنتاج متعدد المثيلات يلزم Redis أو مخزن مشترك.
- الملفات التنفيذية غير مسموحة، والحد 12MB، والصوت 10MB. لا يوجد ماسح برمجيات خبيثة خارجي؛ لذلك يلزم ربط ClamAV/خدمة فحص قبل إنتاج عام.
- لا تُسجل كلمات المرور أو OTP أو مفاتيح AI.

## النسخ الاحتياطي والاستعادة

```bash
set -a; source .env; set +a
bash scripts/backup.sh
bash scripts/restore.sh backups/rafeeq-TIMESTAMP.dump
```

اختبر الاستعادة دوريًا في قاعدة منفصلة، ولا تستعد نسخة إنتاج فوق قاعدة حية دون نافذة صيانة.

## API الرئيسية

المصادقة تحت `/api/auth/*`، والمواد `/api/courses`، المحتوى `/api/content`، الملفات `/api/files`، الواجبات `/api/assignments`، الاختبارات `/api/exams`، الملاحظات `/api/notes`، المزامنة `/api/sync`، المجتمع `/api/community`، الدعم `/api/support`، الذكاء الاصطناعي `/api/ai`، الإدارة `/api/admin`، والمندوب `/api/representative`.

كل API خاصة تتطلب cookie جلسة HttpOnly. مسارات الإدارة والمندوب تعيد 403 عند فشل الدور أو الاعتماد.

## نسخة Android التجريبية

يوجد APK تجريبي في `public/downloads/rafeeq-beta.apk` وصفحة تنزيل في `/download`. بُني الغلاف الأصلي من `android/` للحزمة `com.farouq.rafeeq.beta`، بحد أدنى Android 7.0 وTarget API 35. التوقيع Debug وليس مفتاح إصدار إنتاج، وعنوان الخادم المضمّن هو رابط المعاينة المؤقت. يلزم قبل النشر الحقيقي ضبط نطاق HTTPS دائم، مفتاح توقيع محفوظ آمنًا، وبناء Release واختباره على أجهزة حقيقية.

## قيود معروفة

- نجح رد Gemini النصي الحقيقي واتصال SMTP وقبول طلب إرسال؛ تلخيص PDF وتحويل ملف صوتي حقيقي ما زالا بحاجة لاختبار ملفات فعلية، كما لم يُتحقق من وصول البريد إلى صندوق حقيقي.
- قارئ PDF يعتمد عارض المتصفح؛ التكبير والتنقل متاحان حسب المتصفح، لكن حفظ آخر صفحة مخصص غير منفذ.
- Offline يعمل للملفات والملاحظات واللقطة والجدول؛ تسليم الواجب والمجتمع وAI يتطلب الخادم.
- الدعم محفوظ ويُحدّث بالطلب الدوري، وليس WebSocket فوريًا.
- لوحة الإدارة تدعم اعتماد المندوبين وإدارة الحسابات وكلمات المرور والحالة والتوثيق وقراءة تذاكر الدعم والرد عليها؛ واجهات CRUD المرئية لجميع الكيانات الأكاديمية الأخرى ما زالت جزئية.
- لا توجد خدمة Push أو OCR منفصلة أو تحويل عملات موثوق؛ لا تعرض الواجهة أنها تعمل.
- تخزين الملفات المحلي يحتاج S3-compatible storage أو volume دائم مشترك للإنتاج متعدد الخوادم.
